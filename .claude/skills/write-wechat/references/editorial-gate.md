# 公众号编辑门禁

交付成稿或审稿时使用。门禁的作用是直接修正可修问题，并阻止不可靠内容被标成成稿。

## 阻断问题

以下任一存在时不得判定可发布：

- 核心事实错误、时效性未核实或来源不支持当前措辞强度；
- 虚构亲历、人物、采访、引语、对话、地点、时间或产品体验；
- 标题与摘要承诺正文无法兑现；
- 高风险建议缺少来源、前置条件或必要限制；
- 关键代码、命令、链接、专有名词或操作步骤被改坏；
- 主要结构、例子或措辞明显复制单一来源；
- 文章回答的问题与任务书或用户请求不同。

## 五维复检

### 准确

关键事实可追溯，事实、推断、观点和个人材料没有混写。具体数字、日期、引语与当前状态逐项对账。

### 观点

核心判断明确，有理由、反方与适用边界。资料服务于判断，而不是简单堆叠。

### 实用

读者知道下一步如何行动、判断或选择，也知道前置条件、代价与失败信号。

### 合声

符合账号、栏目和用户样本。声音自然，不冒充经历，不用促销腔掩盖证据不足。

### 好读

开头迅速进入主题，章节持续推进，手机端段落自然，结尾完成一个明确任务。

## 去模板化

不要用固定禁词表机械替换。重点寻找并修正：

- 空洞时代背景和“本文将带你”式预告；
- 连续、整齐、缺乏信息差的三段式与列表；
- “众所周知”“业内认为”等模糊归因；
- 没有事实支撑的宏大形容词、万能金句和结果保证；
- 为显得口语化而硬塞反问、感叹、网络词与假体感；
- 每节重复小结，结尾再次复述全文。

自然化时打破的是机械节奏，不是逻辑、事实和专业准确度。允许朴素句子，允许章节长短不一，也允许没有故事。

## 发布包检查

- 主标题与正文一致，备选标题采用不同机制。
- 摘要增加对象、价值或场景信息，不只重复标题。
- 内部标签控制在 3 至 5 个，不强塞入正文。
- 封面方向描述信息与情绪，不伪造数据、品牌背书或产品 UI。
- CTA 与文章目标一致，只有一个主要动作，不诱导或夸大。
- 图片、HTML 转换、草稿上传和正式发布的状态明确，不把计划写成完成。

用户要求实际出图时，还要打开成图检查裁切、文字、事实、Alt 与正文插入位置；只检查提示词不等于图片验收。

## 结论

输出 `可发布`、`修改后可发布` 或 `需要补充材料`。优先直接修复现有材料能解决的问题；仍受限时缩小承诺，不用虚构内容保住篇幅。
