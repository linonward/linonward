<Step id="write-file" number={1} title="实现带前置条件的写入工具">

创建 `src/tools/write-file.ts`。调用方必须同时提交它读取到的旧内容；文件已经变化时，写入会失败并要求重新读取。

```typescript
const inputSchema = z.object({
  path: z.string().min(1),
  expected: z.string(),
  content: z.string(),
});

export const writeFileTool: Tool<z.infer<typeof inputSchema>, WriteResult> = {
  name: "write_file",
  description: "Replace a text file only when its current content matches expected",
  schema: inputSchema,
  async execute(input, context) {
    const path = resolveWorkspacePath(context.cwd, input.path);
    const current = await readFile(path, "utf8");
    if (current !== input.expected) throw new Error("file_changed");
    await writeFile(path, input.content, "utf8");
    return { path: input.path, bytes: Buffer.byteLength(input.content) };
  },
};
```

</Step>

<Step id="track-files" number={2} title="记录所有变更文件">

给工具增加 `effect: "read" | "write" | "execute"`。当写入成功时，由 Harness 更新状态，而不是让每个工具自行修改全局状态。

```typescript
if (tool.effect === "write" && observation.ok) {
  const path = getChangedPath(observation.output);
  if (!state.changedFiles.includes(path)) state.changedFiles.push(path);
}
```

</Step>

<Step id="update-prompt" number={3} title="要求模型先读再写">

创建 `src/prompt.ts`，加入确定的执行约束：修改前必须读取最新内容；改动保持最小；不编辑生成目录；写入失败后必须重新调查，不能反复提交旧内容。

```typescript
export const instructions = [
  "修改文件前先读取最新内容。",
  "只修改完成任务所需的最小范围。",
  "不要编辑 node_modules、dist 或构建产物。",
  "file_changed 后重新读取，不要重复同一调用。",
].join("\n");
```

</Step>
